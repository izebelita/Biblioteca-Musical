# 🎵 Sistema Musical

## Sobre o projeto
O Sistema Musical é um projeto desenvolvido para organizar e apresentar informações sobre artistas e músicas. O sistema possui páginas para cadastro de artistas, cadastro de músicas e visualização de uma biblioteca musical.

## Funcionalidades
- **Tela de Login:** acesso à página inicial do sistema.
- **Cadastro de Artistas:** permite preencher informações como nome, gênero musical, país e imagem.
- **Cadastro de Músicas:** permite inserir título, artista, álbum, gênero, link do YouTube, capa e letra da música.
- **Biblioteca Musical:** apresenta as músicas cadastradas, com opções de pesquisa e filtros por artista e gênero.

## Tecnologias utilizadas
- HTML
- CSS

## Arquivos do projeto
- `index.html` – Página inicial do sistema.
- `login.html` – Tela de login.
- `cadastro_artista.html` – Cadastro de artistas.
- `cadastro.musica.html` – Cadastro de músicas.
- `listagem_musicas.html` – Listagem das músicas.
- `style.css` – Arquivo responsável pela aparência e organização das páginas.

## Como executar
1. Baixe ou clone os arquivos do projeto.
2. Salve todos os arquivos na mesma pasta.
3. Abra o arquivo `login.html` em um navegador.
4. Utilize os dados de teste para acessar:
   - **Usuário:** admin
   - **Senha:** 123

## Objetivo
O objetivo do projeto é desenvolver um sistema simples e organizado para cadastrar artistas e músicas, além de facilitar a visualização e a busca de informações em uma biblioteca musical.
